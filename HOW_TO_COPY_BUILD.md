# Как правильно скопировать код билда из Path of Building

## Проблема
При копировании кода билда из Path of Building через буфер обмена могут возникать ошибки:
- `Incorrect padding` - код обрезан
- `incomplete or truncated stream` - данные неполные

## Решение: Используйте файл

### Способ 1: Через файл (РЕКОМЕНДУЕТСЯ)

1. **В Path of Building:**
   - Откройте свой билд
   - Нажмите кнопку **"Import/Export Build"**
   - Нажмите **"Generate"**
   - Нажмите **Ctrl+A** (выделить всё)
   - Нажмите **Ctrl+C** (скопировать)

2. **Сохраните в файл:**
   - Создайте файл `build_code.txt` в папке с проектом
   - Откройте его в текстовом редакторе (Notepad, VS Code, и т.д.)
   - Вставьте код (**Ctrl+V**)
   - **ВАЖНО:** Убедитесь, что весь текст на **ОДНОЙ строке** без переносов
   - Сохраните файл

3. **Запустите тест:**
   ```bash
   python test_from_file.py
   ```

### Способ 2: Через экспорт в файл

1. **В Path of Building:**
   - Откройте свой билд
   - Нажмите **"Import/Export Build"**
   - Нажмите **"Generate"**
   - Нажмите **"Save to Clipboard"** или скопируйте вручную

2. **Альтернатива - используйте Export:**
   - В PoB: `Build → Save to file`
   - Сохраните как XML файл
   - Но наш парсер работает с кодированными билдами, не с XML

### Способ 3: Через аргумент командной строки

```bash
python test_jewels_simple.py "ваш_очень_длинный_код_билда"
```

Но это может не работать в Windows PowerShell из-за ограничений длины команды.

## Частые ошибки

### ❌ Код слишком короткий
```
Длина кода: 150 символов
```
**Причина:** Скопирована только часть кода
**Решение:** Убедитесь, что используете Ctrl+A перед копированием

### ❌ Переносы строк
```
eNrtfW1z27i
y8OejX8HxTJ
8vcWzineyT
```
**Причина:** Редактор добавил переносы строк
**Решение:** Код должен быть одной строкой

### ❌ Лишние пробелы
```
eNrt fW1z 27iy
```
**Причина:** При копировании добавились пробелы
**Решение:** Используйте простой текстовый редактор (Notepad), не Word

## Проверка корректности

Правильный код билда:
- ✓ Длина: **несколько тысяч символов** (обычно 3000-10000+)
- ✓ Начинается с букв, например: `eNrt...`
- ✓ Содержит только символы: `a-z`, `A-Z`, `0-9`, `-`, `_`
- ✓ Одна строка без переносов

Пример начала правильного кода:
```
eNrtfW1z27iy8OejX8HxTJ8vcWzineyTnDvyu9O4cW0nafulAxKgxZoiXZKy4585...
```

## Тестовые скрипты

1. **test_from_file.py** - читает из файла build_code.txt (РЕКОМЕНДУЕТСЯ)
2. **test_jewels_simple.py** - читает из аргумента или stdin
3. **test_jewels_diagnosis.py** - детальная диагностика (только stdin)

## Нужна помощь?

Если код все равно не работает:
1. Проверьте размер файла build_code.txt - он должен быть хотя бы 3-5 KB
2. Откройте файл в текстовом редакторе и проверьте, что там одна длинная строка
3. Убедитесь, что в коде нет символов кириллицы или специальных символов
