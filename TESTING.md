# Инструкция по тестированию парсера

## Быстрые тесты

### 1. Базовый тест парсера
```bash
python3 test_parser.py
```
Проверяет базовую функциональность парсинга одного предмета.

### 2. Комплексный тест
```bash
python3 test_comprehensive.py
```
Проверяет парсинг jewels, flasks и разделение на префиксы/суффиксы.

### 3. Тест эвристики
```bash
python3 test_improved_heuristic.py
```
Проверяет точность определения префиксов/суффиксов (должна быть 100%).

## Тестирование с реальным билдом

### Шаг 1: Скопируйте код билда из Path of Building

1. Откройте Path of Building
2. Загрузите свой билд
3. Нажмите **Import/Export Build** → **Generate** → **Share with Pastebin**
4. Скопируйте код (длинная строка, начинающаяся с букв и цифр)

### Шаг 2: Запустите тест

```bash
python3 test_real_build.py
```

После запуска:
1. Вставьте код билда
2. Нажмите Enter
3. Нажмите Ctrl+D (Linux/Mac) или Ctrl+Z (Windows)

### Шаг 3: Анализ результатов

Скрипт выведет:
- ✓ **Экипировку** с разделением модов на префиксы и суффиксы
- ✓ **Самоцветы (Jewels)** с их модами
- ✓ **Флаконы (Flasks)** с их модами
- ⚠ **Проблемы** если они обнаружены

Результаты также сохраняются в `build_analysis.json` для детального анализа.

## Тестирование веб-интерфейса

### Шаг 1: Запустите сервер

```bash
python3 app.py
```

### Шаг 2: Откройте браузер

Перейдите на http://localhost:5000

### Шаг 3: Вставьте код билда

1. В поле ввода вставьте код билда из Path of Building
2. Нажмите "Парсить билд"
3. Проверьте результаты:
   - Экипировка должна показывать префиксы и суффиксы отдельно
   - Самоцветы должны быть в отдельном разделе
   - Флаконы должны быть в отдельном разделе

## Что проверять

### ✓ Экипировка
- [ ] Префиксы выделены отдельно
- [ ] Суффиксы выделены отдельно
- [ ] Крафтовые моды отмечены
- [ ] Имплициты отображаются

### ✓ Самоцветы (Jewels)
- [ ] Все jewels найдены и отображены
- [ ] Моды jewels корректно показаны
- [ ] % increased maximum Life определен как суффикс

### ✓ Флаконы (Flasks)
- [ ] Все флаконы найдены и отображены
- [ ] Моды флаконов корректно показаны
- [ ] Свойства флаконов (время действия, восстановление) отображаются

## Отладка проблем

### Если jewels не находятся
Проверьте:
1. Слот должен содержать "jewel" в названии, или
2. Тип предмета (base) должен содержать "jewel", или
3. Название предмета должно содержать "jewel"

### Если flasks не находятся
Проверьте:
1. Слот должен содержать "flask" в названии, или
2. Тип предмета (base) должен содержать "flask"

### Если моды не классифицируются
1. Запустите `test_improved_heuristic.py` для проверки точности
2. Проверьте `build_analysis.json` для детального анализа
3. Откройте issue с примером мода

## Примеры правильной классификации

### Префиксы
- `+50 to maximum Life` → Flat жизнь
- `+40 to maximum Mana` → Flat мана
- `Adds 10-20 Physical Damage` → Добавленный урон
- `30% increased Physical Damage` → Увеличенный урон (на оружии)
- `+1 to Level of all Fire Skill Gems` → Уровень гемов

### Суффиксы
- `10% increased maximum Life` → % жизнь
- `+35% to Fire Resistance` → Сопротивление
- `+25 to Strength` → Атрибут
- `12% increased Attack Speed` → Скорость
- `18% increased Rarity of Items found` → Редкость
- `+250 to Accuracy Rating` → Точность
- `+30% to Critical Strike Multiplier` → Крит мультипликатор
