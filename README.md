# PoE Build Converter

Полнофункциональный конвертер билдов Path of Building с красивым веб-интерфейсом.

## 🚀 Возможности

- ✅ **Полный парсинг** всех данных из билдов PoB
- 🎨 **Красивый веб-интерфейс** с темной темой
- 📊 **Интерактивные вкладки** для разных типов данных
- 🎒 **Предметы** - все экипированные предметы с модами и редкостью
- 💎 **Скиллы и Гемы** - полная информация о скиллах и сокетах
- 🌳 **Пассивное дерево** - количество выбранных узлов
- ⚙️ **Конфигурация** - все настройки билда
- 📝 **Заметки** - заметки автора билда
- 📋 **Копирование** - легкое копирование названий предметов

## 🛠 Установка

```bash
# Установите зависимости
pip install -r requirements.txt
```

## 💻 Использование

### Веб-интерфейс (рекомендуется)

```bash
python app.py
```

Откройте браузер и перейдите по адресу: **http://localhost:5000**

**Инструкции:**
1. Скопируйте код билда из Path of Building
2. Вставьте в текстовое поле
3. Нажмите "Парсить билд" или используйте **Ctrl+Enter**
4. Используйте вкладки для навигации по данным

### Консольный интерфейс

```bash
python main.py
```

Вставьте код билда когда программа попросит.

## 🎯 Что парсится из билда

1. **Основная информация** - класс, подкласс, уровень
2. **Предметы** - все экипированные предметы с полными характеристиками
3. **Скиллы** - все скиллы с гемами, уровнями и качеством
4. **Пассивное дерево** - выбранные узлы и спецификации
5. **Конфигурация** - все настройки расчетов
6. **Заметки** - текстовые заметки автора
