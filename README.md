# PoE Build Converter

Конвертер билдов Path of Building для удобного просмотра и копирования информации о предметах.

## Использование

```bash
python main.py
```

Вставьте код билда из Path of Building когда программа попросит.

## Что делает программа

1. Принимает код билда PoB (закодированная строка)
2. Декодирует и парсит XML данные
3. Извлекает информацию о предметах персонажа
4. Красиво форматирует вывод для удобного копирования
